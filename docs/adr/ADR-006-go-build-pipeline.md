# ADR-006 Go build pipeline

Status: Accepted 2026-10-25

**Decision.** `Engine/scripts/build-xcframework.sh` builds device slices only: `arm64-apple-macos26.0` (with `-ldflags -macos=26.0 -macsdk=27.0`; 26.0 since the ADR-002 amendment), `arm64-apple-ios27.0`, `arm64-apple-tvos27.0`; `-buildmode=c-archive -trimpath -ldflags "-w -X main.appVersion=… -X main.build=… -X main.scriptSHA=…"`; `CGO_CFLAGS`/`CGO_LDFLAGS` with `-isysroot <sdk> -target <triple>`; `GOTOOLCHAIN=local GOFLAGS=-mod=vendor GOPROXY=off`; separate `GOCACHE` per slice under `$CLEAN_DEV_BUILDS`; output `WGEXEngine.xcframework` in a git-ignored `Binary` directory (inside the `Packages/WGEXEngine` package root, as SwiftPM requires; git-ignored); Clang module `CWGEXEngine`; `verify-slices.sh` checks `LC_BUILD_VERSION` on every archive member including `go.o`; provenance JSON embedded and exposed by `wgex_build_info()`. **Simulator Go slices are not built** (golang/go#57442; providers do not run in the simulator); the amendment below supersedes this: simulator slices are built and `WGEXEngineStub` no longer exists. A `wgextest`-tagged test-support archive (`WGEXEngineTest.xcframework`, macOS slice) carries netstack pairs for Swift loopback tests and is never linked into products; `just check` asserts no `_wgex_test_` symbols and no `gvisor.dev` in production archives.

**Amendment (25 October 2026).** A host experiment with Go 1.27.3 and Xcode 27.1 showed that c-archive builds with `-target arm64-apple-ios27.0-simulator` (iphonesimulator SDK) and `-target arm64-apple-tvos27.0-simulator` (appletvsimulator SDK) carry `LC_BUILD_VERSION` platform 7 and 8 on every member including `go.o` (the Go linker copies the platform from the first cgo object), and Xcode's `ld` links them without warnings; golang/go#57442 does not apply to this toolchain. Decision: the XCFramework gains two simulator slices (`ios-arm64-simulator`, `tvos-arm64-simulator`); the provider and app targets link `WGEXEngine` on every destination; `WGEXEngineStub` was kept as a test double for callers until 26 October 2026, when it was removed as dead (tests use `FakeEngine`); `verify-slices.sh` expects platforms 7 and 8 for those slices. Simulator unit tests may exercise the real engine in-process against the userspace test peer; the provider itself still cannot run in the simulator.
