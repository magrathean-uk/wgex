# ADR-016 Project structure and identifiers

Status: Accepted 2026-10-25

**Decision.** XcodeGen `project.yml`, local SwiftPM packages, `just` recipes. **All identifiers derive from one xcconfig variable `WGEX_BUNDLE_ID_BASE`** (`com.magrathean.WGEXApp` in Release, `com.magrathean.WGEXApp.dev` in Debug): app `<base>`, tunnel extension `<base>.tunnel`, Live Activity `<base>.liveactivity`, daemon label and Mach service `<base>.daemon`, CLI `<base>.cli`, app group `group.<base>`, keychain group `$(AppIdentifierPrefix)<base>`, log subsystem `<base>`; a pre-build step generates `BuildIdentifiers.swift` and preprocesses the launchd plist. `PRODUCT_NAME` is `WGEX` for the apps and `wgex` for the CLI (embedded at `WGEX.app/Contents/Helpers/`, never `WGEX.app/Contents/MacOS/`, which is the app binary on a case-insensitive volume). Tools embed an Info.plist (`CREATE_INFOPLIST_SECTION_IN_BINARY`) so their signing identifiers match the requirement strings. Mac app entitlements include `keychain-access-groups` and `com.apple.security.application-groups`, which need Mac Development and Developer ID provisioning profiles; the host Mac and each lab guest are registered as Mac devices. The iOS app carries `com.apple.developer.networking.wifi-info` for SSID capture, `NSSupportsLiveActivities`, local-network and Bonjour keys; the Mac and tvOS apps carry the local-network and Bonjour keys too.
