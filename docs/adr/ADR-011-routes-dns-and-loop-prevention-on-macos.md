# ADR-011 Routes, DNS and loop prevention on macOS

Status: Accepted 2026-10-25

**Decision.** Interface addressing and MTU via the `CWGEXSysShim` C target; routes via `PF_ROUTE` with `RTF_PROTO2` ownership marks and journalled interface identity; `/1` split defaults for full tunnels. **Loop prevention is `IP_BOUND_IF`/`IPV6_BOUND_IF` on every engine, carrier and resolver socket; there are no endpoint escape routes** (revision 1's escape routes were redundant with bound sockets, wrong for on-link endpoints and unmatchable by the ownership check). Underlay per family from `State:/Network/Global/IPv4|IPv6` `PrimaryInterface`, with `NWPathMonitor(prohibitedInterfaceTypes: [.other, .loopback])` as a secondary signal; sockets rebound per family on change; MTU recomputed on every underlay change. DNS: a single `State:/Network/Service/<WGEX-UUID>/DNS` key with `SupplementalMatchDomains: [""]` for full tunnel (Tailscale's shipping pattern), `SearchOrder` fixed by P4-04, created as a temporary value on the daemon's session, updated by remove-then-add; verification parses `scutil --dns` (read-only external process); fallback is journalled per-service `Setup:` writes with conditional restoration. Endpoint resolution under blocking policies uses the daemon-owned `UnderlayResolver` (root sockets bound to the underlay, resolvers from the primary service), never mDNSResponder.
